# Tanish — Electric Vehicle Market Performance & Insights

Responsive project showcase website.

## Publish with GitHub Pages
1. Create a public GitHub repository named `ev-market-insights`.
2. Upload `index.html` to the repository root and commit it.
3. Open Settings → Pages.
4. Choose Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Your website URL will be `https://YOUR-USERNAME.github.io/ev-market-insights/`.

Replace YOUR-USERNAME with the actual GitHub username. Add verified dataset findings and your Tableau Public dashboard URL before final submission.
